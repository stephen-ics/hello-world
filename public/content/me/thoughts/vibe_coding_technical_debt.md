# Vibe Coding & Technical Debt

*June 2025*

This summer I decided to heavily vibe-code an app that I am working on. I say heavily vibe-coded because I understood overall how the codebase operated and what each file and function did. However, if you asked me to point out what a specific line or piece of syntax meant, I may not be able to answer correctly.

At first it was absolutely amazing, I was able to produce a prototype of my app within a day, a task that would usually require multiple all nighters. But I was bearing **technical debt**, at a high interest rate at that. As time went on, I added in more features and things quickly began to fall part. The main problem? **AI has a short memory** there is only so much context you can provide it, and overtime it began to write redundant and nonsensical code.

I like to think of vibe coding as the loan sharks of the developing world. They *could* be very helpful but you must be VERY careful or else you'll go bankrupt!
